# supermercado

# Pre requisitos
-	Mariadb
-	Dotnet 10
-	VSCode
# Pasos para hacer correr el proyecto
1.	Clonar el Repositorio
```
git clone https://github.com/asgorex/supermercado.git
cd supermercado
```
2.	Crear la base de datos y las tablas, corriendo el archivo base.sql en su SGBD
3.	Correr la aplicacion
```
dotnet run
```
